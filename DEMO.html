🚀 Deployment Instructions

Step 1: Deploy Backend to EC2
Run: ./aws/deploy-backend.sh
This deploys PHP backend to Amazon EC2 with Apache server
Step 2: Update Frontend Configuration
Update frontend/js/config.js with your EC2 IP address
Step 3: Deploy Frontend to S3
Run: ./aws/deploy-frontend.sh
This deploys static files to Amazon S3 with static website hosting

📊 API Endpoints

Products API:
  • GET /products.php?action=list - List all products
  • GET /products.php?action=get&id={id} - Get product details
  • GET /products.php?action=search&q={query} - Search products
  • GET /products.php?action=categories - Get categories
Cart & Checkout API:
  • GET /cart.php?action=get - Get cart contents
  • POST /cart.php?action=add - Add item to cart
  • POST /cart.php?action=update - Update cart item
  • POST /cart.php?action=remove - Remove from cart
  • POST /checkout.php - Process order
